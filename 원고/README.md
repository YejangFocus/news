# 기사 원고 → 기사 페이지 자동 생성

`원고/<분류>/<이름>.md` 파일을 올리면 GitHub Actions 가 `<분류>/<이름>.html` 을 만들고,
기사 목록·링크 미리보기·검색·사이트맵까지 자동으로 갱신합니다.

1. `원고/_양식.md` 를 복사해 `원고/목회/새기사.md` 처럼 분류 폴더 안에 저장합니다.
2. 사진은 `assets/images/` 에 올리고 `![설명](assets/images/파일.jpg "캡션")` 으로 넣습니다(WebP 변환은 자동).
3. main 에 올리면 끝입니다. 이미 있는 손으로 만든 HTML 은 덮어쓰지 않습니다.

지원하는 서식: `## 소제목`, `### 소제목`, 문단, `**굵게**`, `*기울임*`, `[링크](주소)`, 사진+캡션, `> 인용`(마지막 줄을 `— 출처` 로),
`-` 목록, `1.` 번호 목록. 표나 통계 막대처럼 복잡한 부분은 HTML 을 빈 줄로 구분해 그대로 넣으면 통과합니다.
이름이 `_` 로 시작하는 파일은 건너뜁니다.
